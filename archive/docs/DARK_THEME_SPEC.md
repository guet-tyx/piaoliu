# 漂流 DRIFT · 星海版 — 深海配色方案（Dark Theme Spec）

> 设计：汐 · 星海版美术 | 日期：2026-08-02
> 用途：替换当前浅色面板为深海背景，保留白色卡片做"纸船"对比

---

## 一、方案概述

**整体思路**：将 body 整页底色改为深空蓝渐变，保留现有卡片（panel）白色 — 即"深海中的白色纸船卡片"视觉隐喻。

**不改的部分**：
- 卡片内部白底 `--panel: #FFFFFF`（纸船感）
- 粉色/蓝色品牌色（已适配深色）
- Hero 区域（本身已是深空）
- 浅灰文字层级（改为浅色后需调整）

**要改的部分**：
- `body` 背景：浅粉渐变 → 深空蓝渐变
- `--panel-2` 次级面板：`#F1F2F3` → 浅空蓝
- 卡片阴影：深灰色阴影 → 粉/青辉光
- 顶栏：亮色毛玻璃 → 深色毛玻璃
- 文字色：深文字 → 浅文字

## 二、完整 CSS 变量方案

### 2.1 背景层

```css
:root {
  /* 深海底色 —— 替换 body 背景 */
  --bg:        #0B1020;   /* 主深空蓝（原 #F6F7F8） */
  --bg-top:    #050C1E;   /* 顶部更深层（原 #FDF2F7） */
  --bg-deep:   #03060F;   /* 最深空（用于卡片背景或分区） */

  /* 卡片面板（纸船感，保留白色） */
  --panel:     #FFFFFF;   /* 主卡片白底（不变） */
  --panel-2:   #F0F4FA;   /* 次级面板（原 #F1F2F3，微蓝调） */

  /* 品牌色（已适配，不变） */
  --pink:       #FB7299;
  --pink-bright:#FF9BB5;
  --pink-deep:  #F2597F;
  --blue:       #00AEEC;
  --blue-bright:#40C5F1;
  --blue-deep:  #008AC5;
  --gold:       #C9A063;
  --ice:        #7BB1FF;

  /* 文字色 —— 翻转为浅色系 */
  --ink:   #F1EDE3;        /* 主文字（原 #18191C） */
  --ink-2: #B8C0CC;        /* 次文字（原 #61666D） */
  --ink-3: #6B7280;        /* 辅助文字（原 #9499A0） */
  --ink-4: rgba(241,237,227,0.5); /* 极浅文字（新增） */

  /* 边框/分隔线 —— 翻转为浅色 */
  --line:   rgba(123, 177, 255, 0.15);  /* 主分隔线（原 #E3E5E7） */
  --line-2: rgba(123, 177, 255, 0.08);  /* 次分隔线（新增） */
}
```

### 2.2 body 背景

```css
body {
  background:
    radial-gradient(ellipse 60% 30% at 30% 0%, rgba(251,114,153,0.08), transparent 70%),
    radial-gradient(ellipse 60% 30% at 70% 0%, rgba(0,174,236,0.08), transparent 70%),
    linear-gradient(180deg, #03060F 0%, #050C1E 120px, #0B1020 280px, #0B1020 100%);
  color: var(--ink);
}
```

说明：
- 顶部 `#03060F` 与 Hero 视频衔接，无断裂感
- 120px 处过渡到 `#050C1E`，保持深空蓝
- 顶部分别加粉、蓝径向光晕，模拟"星海天顶光"
- 内容区整页深空蓝，卡片白色漂浮其中

### 2.3 卡片阴影（粉/青辉光替代深灰阴影）

```css
/* 替换所有卡片 .shadow / box-shadow 中的深灰阴影 */
.card {
  box-shadow:
    0 24px 56px -36px rgba(24, 25, 28, 0.6),    /* 深空晕影（深色版） */
    0 2px 6px rgba(24, 25, 28, 0.15),
    0 0 32px -8px rgba(251, 114, 153, 0.06);     /* 粉辉光（新增） */
}
.card:hover {
  box-shadow:
    0 34px 66px -38px rgba(24, 25, 28, 0.7),
    0 18px 40px -12px rgba(251, 114, 153, 0.12); /* hover 粉辉光增强 */
}
```

### 2.4 顶栏（Topbar）

```css
/* Topbar.module.css 改动 */
.topbar {
  background: rgba(5, 12, 30, 0.86);    /* 原 rgba(255,255,255,.86) */
  border-bottom: 1px solid var(--line);
}
.topbarIn a {
  color: var(--ink-2);                   /* 原 #61666D */
}
.topbarIn a:hover {
  color: var(--ink);                     /* 原 #18191C */
}
.brandName {
  color: var(--ink);                     /* 原深色 */
}
.brandMark {
  background: linear-gradient(135deg, var(--pink), var(--blue));
  color: #fff;                           /* 不变 */
}
.navLinks .navDl {
  color: #fff;                           /* 不变 */
}
```

### 2.5 卡片白底 + 深色文字（核心：保持"纸船"感）

卡片内部背景、文字、按钮**全部维持原样不变**：

```css
/* 卡片容器（保持白色底） */
.card, .section-content {
  background: var(--panel);       /* 白色 #FFFFFF */
  color: var(--ink);             /* 卡片内深文字（注意：卡片内用深色文字！） */
}
```

⚠️ **重要规则**：卡片内部文字色保持深色（`#18191C`），卡片外部（body/section 级）文字色用浅色（`#F1EDE3`）。

卡片内部文字色不需要改——因为只有卡片外的文字需要变浅。

| `PlayerSection.module.css` | 同上 | ⭐ 简单 |

## 四、执行优先级

1. **Step 1**：改 `globals.css` 中 `--bg`/`--bg-top`/`--ink`/`--ink-2`/`--ink-3`/`--line`/`--panel-2` 变量值
2. **Step 2**：改 `body` 背景为深海渐变
3. **Step 3**：改 `Topbar.module.css` 顶栏为深色毛玻璃
4. **Step 4**：全局排查硬编码浅色 `#18191C`/`#61666D`/`#9499A0`，替换为 `var(--ink)`/`var(--ink-2)`/`var(--ink-3)`
5. **Step 5**：全局排查卡片外文字色是否使用了 `var(--ink)` 而非硬编码

## 六、需要排查的硬编码颜色

全局搜索以下颜色，替换为 CSS 变量：

```
#18191C  → var(--ink)     （卡片内文字，保留）
#61666D  → var(--ink-2)   （卡片内外均可）
#9499A0  → var(--ink-3)   （卡片内外均可）
#E3E5E7  → var(--line)    （卡片内边框）
#F1F2F3  → var(--panel-2) （卡片内次级背景）
#F6F7F8  → var(--bg)      （卡片外背景，需翻转）
#FDF2F7  → var(--bg-top)  （卡片外背景，需翻转）
```
